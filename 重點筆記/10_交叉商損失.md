# 10｜交叉熵損失 Cross-Entropy Loss

[← 學習目錄](README.md) ｜ [梯度下降](02_梯度下降.md) ｜ [CNN](03_CNN.md) ｜ [Transformer](06_Transformer.md)

## 1. 一句話理解

**交叉熵損失（Cross-Entropy Loss）是分類任務常用的損失函數，衡量模型分配給「正確類別」的機率有多低。**

以貓狗分類為例，照片實際是貓：

| 模型預測貓的機率 | 預測狗的機率 | 交叉熵損失（約） | 解讀 |
|---:|---:|---:|---|
| 99% | 1% | 0.010 | 非常有把握且正確 |
| 90% | 10% | 0.105 | 表現不錯 |
| 60% | 40% | 0.511 | 還不夠確定 |
| 20% | 80% | 1.609 | 偏向錯誤類別 |
| 1% | 99% | 4.605 | 非常有把握但錯誤，懲罰更大 |

**記憶法：正確答案的機率越高，Loss 越低；越低，Loss 越高。**

> 以上是假設二分類且真實標籤是「貓」，以自然對數計算；這裡的機率是教學示意。

## 2. 公式怎麼看？

單筆資料、真實類別已知時：

$$L=-\ln(p_{\text{correct}})$$

- $L$：損失值。
- $p_{\text{correct}}$：模型給正確類別的預測機率（介於 0 和 1）。
- $\ln$：自然對數。

多類別的一般形式：

$$L=-\sum_{i=1}^{C} y_i\ln(p_i)$$

其中 $C$ 是類別數，$y_i$ 是 one-hot 真實標籤（正確類別為 1，其他為 0），$p_i$ 是預測機率。因為只有正確類別的 $y_i=1$，所以簡化成上一個公式。

若預測機率恰為 0，$\ln(0)$ 不存在；實際計算應使用數值穩定的方法。

## 3. 純 Python：不需要 NumPy

```python
import math

# 真實答案是「貓」
cat_probabilities = [0.99, 0.90, 0.60, 0.20, 0.01]

for p_cat in cat_probabilities:
    loss = -math.log(p_cat)
    print(f"貓的預測機率: {p_cat:.0%} | Cross-Entropy Loss: {loss:.3f}")
```

這個例子直接使用「正確類別的機率」，適合初學者理解 Loss。

## 4. Softmax 與 Cross-Entropy 有什麼關係？

分類模型通常先輸出 **logits（未正規化分數）**，例如 `[2.0, 0.5]`，而不是直接輸出百分比。

```text
圖片 → CNN → logits [2.0, 0.5]
                  ↓ Softmax
             [0.818, 0.182]（機率）
                  ↓ Cross-Entropy（正確答案：貓）
             Loss ≈ 0.201
```

Softmax 把 logits 轉為總和為 1 的類別機率。Cross-Entropy 再衡量正確類別機率是否夠高。

**重要：PyTorch 的 `nn.CrossEntropyLoss()` 已在內部以數值穩定方式處理 LogSoftmax 與 NLLLoss；傳入原始 logits，不要先自行呼叫 Softmax。**

## 5. PyTorch：分類損失與梯度下降

安裝：`pip install torch`

```python
import torch
from torch import nn

# 一筆資料，兩類：0=貓、1=狗
logits = torch.tensor([[2.0, 0.5]], requires_grad=True)
label = torch.tensor([0])  # 正確答案是貓

criterion = nn.CrossEntropyLoss()
loss = criterion(logits, label)

print("預測機率:", torch.softmax(logits.detach(), dim=1))
print("Loss:", loss.item())

loss.backward()  # 反向傳播：計算 logits 的梯度
print("Gradient:", logits.grad)
```

如果希望看一次「參數更新」：

```python
import torch
from torch import nn

model = nn.Linear(2, 2)  # 兩個輸入特徵，輸出貓/狗 logits
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
criterion = nn.CrossEntropyLoss()

# 假設的兩個輸入特徵，僅供示範
features = torch.tensor([[0.8, 0.2], [0.1, 0.9]])
labels = torch.tensor([0, 1])  # 第一筆是貓，第二筆是狗

optimizer.zero_grad()
logits = model(features)
loss = criterion(logits, labels)
loss.backward()  # 計算梯度
optimizer.step()  # 梯度下降更新權重

print("更新前計算的 Loss:", loss.item())
```

> 上面只示範一次更新；沒有訓練集／測試集或實際圖片，不能據此宣稱模型已經學會辨識貓狗。

## 6. 與梯度下降的差別

| 概念 | 問題 | 角色 |
|---|---|---|
| Cross-Entropy Loss | 模型錯多少？ | 計算分類損失 |
| Backpropagation（反向傳播） | 各參數如何影響 Loss？ | 利用鏈式法則計算梯度 |
| Gradient Descent（梯度下降） | 怎麼修改參數讓 Loss 下降？ | 更新模型參數 |

```text
輸入圖片 → CNN → logits → Cross-Entropy Loss
                                ↓
                         Backpropagation
                                ↓
                         計算各權重梯度
                                ↓
                         Optimizer 更新權重
                                ↓
                            重複訓練
```

## 7. 常見錯誤與補充

- **Cross-Entropy 不是最佳化器**：它計算損失，SGD/Adam 等負責更新參數。
- **Loss 不等於 Accuracy**：Accuracy 只看預測類別是否正確，Cross-Entropy 還反映模型對正確答案的信心。
- **不要先 Softmax 再丟給 `nn.CrossEntropyLoss()`**：該函式預期的是 logits。
- **多類別單標籤**常用 Cross-Entropy；**多標籤分類**（一張圖可同時有多個標籤）常用 `nn.BCEWithLogitsLoss()`，不是同一設定。
- **Loss 下降不代表測試表現一定提升**：仍要觀察驗證集，避免過擬合。

## 8. 自我練習

3. Loss、反向傳播、梯度下降三者分別負責什麼？

**參考答案：** 1. A。2. 原始 logits。3. 分別是衡量錯誤、計算梯度、更新參數。
