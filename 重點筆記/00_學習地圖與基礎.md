## 核心觀念

- **監督式學習**：資料附有標籤，例如貓／狗。
- **分類**：輸出類別；**迴歸**：輸出連續數值。
- **特徵（Feature）**：模型用來判斷的輸入資訊。
- **權重（Weight）**：模型學習調整的參數（決策樹則主要學習分裂規則）。
- **Loss（損失）**：預測和目標的差距。
- **過擬合（Overfitting）**：訓練集表現很好，但未見過的資料表現差。
- **欠擬合（Underfitting）**：模型連訓練資料的規律都沒有充分學到。

## 神經網路訓練流程

```text
輸入 X → 前向傳播 → 預測 y_hat → Loss
                              ↓
                      反向傳播求梯度
                              ↓
                      Optimizer 更新權重
                              ↓
                         重複訓練
```

> 決策樹一般依 Gini / Entropy 等指標選擇分裂條件，**不是**用反向傳播和梯度下降訓練。

## Python：不靠 NumPy 建立矩陣

```python
A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
C = [[A[i][j] + B[i][j] for j in range(2)] for i in range(2)]
print(C)  # [[6, 8], [10, 12]]
```

## NumPy：陣列運算

```python
import numpy as np
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print(A + B)  # 逐元素相加
print(A @ B)  # 矩陣乘法
```
