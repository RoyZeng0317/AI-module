# 02｜梯度下降 Gradient Descent

## 核心觀念

**梯度下降是一種最佳化方法：沿著損失函數下降的方向，逐步調整參數。**

- **Loss**：錯多少。
- **Gradient**：參數稍微改變時，Loss 如何變化。
- **Learning Rate（學習率）**：每次更新的步伐大小。

$$w_{new}=w_{old}-\eta\frac{\partial L}{\partial w}$$

$\eta$ 代表學習率。

## Python：純 Python 梯度下降

目標：找出使 $L(w)=(w-3)^2$ 最小的 $w$；正確最低點是 $w=3$。

```python
w = 0.0
learning_rate = 0.1

for step in range(30):
    loss = (w - 3) ** 2
    gradient = 2 * (w - 3)
    w -= learning_rate * gradient
    if step % 5 == 0:
        print(f'step={step:02d}, loss={loss:.6f}, w={w:.4f}')

print('最後的 w =', w)
```

## Python：PyTorch 自動求梯度

安裝：`pip install torch`

```python
import torch

w = torch.tensor(0.0, requires_grad=True)
optimizer = torch.optim.SGD([w], lr=0.1)

for _ in range(30):
    optimizer.zero_grad()
    loss = (w - 3) ** 2
    loss.backward()   # 自動計算梯度
    optimizer.step()  # 更新 w

print('w =', w.item())
```

## 常見變體

- **Batch GD**：每次用全部訓練資料計算梯度。
- **SGD**：每次用單筆資料更新（術語也常泛指隨機小批次方法）。
- **Mini-batch GD**：每次使用一小批資料；深度學習常見。
- **Adam**：常見自適應最佳化器。

## 易錯觀念

- 學習率太大：可能震盪、發散；太小：可能訓練緩慢。
- 梯度下降不保證找到所有非凸問題的全域最佳解。
- Cross-Entropy 是一種分類損失；梯度下降是降低損失的**方法**，兩者角色不同。
