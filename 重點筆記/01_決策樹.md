## 一句話理解

**決策樹是監督式學習演算法，利用一連串 `if / else` 式的條件，完成分類或迴歸。**

```text
是否有尖耳朵？
├─ 是 → 臉型是否較圓？ → 貓／狗（示意）
└─ 否 → 狗（示意）
```

此圖僅說明分支概念，不是可靠的動物辨識規則。

## 基本結構

| 名稱 | 英文 | 用途 |
|---|---|---|
| 根節點 | Root Node | 最初的判斷 |
| 內部節點 | Internal Node | 中途判斷 |
| 葉節點 | Leaf Node | 最終分類／預測 |

**分類樹**預測類別，**迴歸樹**預測數值。

## 如何選擇分裂條件？

- **Gini impurity（吉尼不純度）**：類別越混雜，數值通常越大；全為同類時為 0。
- **Entropy（熵）**：量測類別不確定性；全為同類時為 0。
- **Information Gain（資訊增益）**：分裂前後不確定性降低的程度。

$$Gini=1-\sum_{k=1}^{K}p_k^2$$

$$H=-\sum_{k=1}^{K}p_k\log_2 p_k$$

$$IG=H(parent)-\sum_i\frac{n_i}{n}H(child_i)$$

其中 $p_k$ 是第 $k$ 類的比例，$n_i/n$ 是子節點樣本比例。

## Python：訓練分類樹

安裝：`pip install scikit-learn`

```python
from sklearn.tree import DecisionTreeClassifier, export_text

# 特徵：[讀書時數, 出席率]；純教學假資料
X = [[1, 50], [2, 60], [4, 80], [6, 90]]
y = [0, 0, 1, 1]  # 0 不及格；1 及格

model = DecisionTreeClassifier(max_depth=2, random_state=42)
model.fit(X, y)
print('預測：', model.predict([[5, 85]])[0])
print(export_text(model, feature_names=['study_hours', 'attendance']))
```

## 過擬合與剪枝

樹越深不代表越好；可能記住訓練資料的雜訊。常見限制：

- `max_depth`：最大深度。
- `min_samples_split`：節點可分裂的最少樣本數。
- `min_samples_leaf`：葉節點最少樣本數。
- `ccp_alpha`：成本複雜度剪枝參數。

## 常見誤解

1. 決策樹**不需要**透過梯度下降來學習分裂。
2. 訓練準確率 100% **不代表**泛化能力好。
3. 決策樹通常不要求像距離模型那樣先標準化數值特徵。
