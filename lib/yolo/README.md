# 物品標註、微調與即時偵測

## 刪除照片與修正類別

- 「刪除未標註照片」只移除尚未確認、沒有框且不是背景負例的照片，已儲存資料會保留。先處理目前未儲存的修改，再依畫面數量確認刪除。
- 類別錯字可用「更名類別」，保留既有框；「刪除類別」會移除該類別所有框，同步調整其餘類別編號，受影響照片須重新確認。至少保留一個類別。
- 刪除與更名前會在工作資料集 `trash/<識別碼>/` 保留原始標註；刪除照片亦保留影像副本。原匯入來源、舊匯出快照與模型不變。
- 相機、訓練或匯出期間不能執行上述資料修改。類別更動後需重新匯出與訓練，舊 `best.pt` 的名稱與類別不會自動更新。
- 修改程式或在外部整理資料後，請重新開啟工具，讓照片與類別清單重新載入。

這個工具用你人工確認的照片教 YOLO 辨識橡皮擦等自訂物品。已授權使用本地 YOLO 預訓練權重微調，不呼叫雲端 AI API。尚未提供真實標註資料，因此目前完成工具流程，沒有訓練好、可保證辨識橡皮擦的模型。

在 AI-module 根目錄啟動：

```powershell
.\.venv\Scripts\python.exe -m lib.yolo.object_labeler
```

需要目前環境已有的 `ultralytics`、支援 CUDA 的 `torch`、`opencv-python`、`Pillow`、`PyYAML` 與 Tkinter。工具不會自動下載模型；起始權重預設為專案根目錄的 `yolo11n.pt`，採用本次50張資料實際比較後較可靠的小資料設定。

1. 按「匯入照片」，或「攝影機預覽」→「擷取這一幀」。擷取後畫面會凍結，才能人工框選；預覽不會自動存檔。
2. 選擇「橡皮擦」，用滑鼠拖曳框住物品。一張照片有多個目標時，請每個都標註。可「新增類別」，類別 ID 依新增順序固定；不要把錯誤模型預測當成正確標註。
3. 畫錯時選取左下方的框清單，再按「刪除選取框」。按「儲存標註」，日後可在左側照片清單重新選取並修改。
4. 沒有任何目標類別的照片，請勾選「背景負例」後儲存；沒畫框也沒確認負例的照片，不會匯出訓練。
5. 使用 `train` 作訓練、`val` 作驗證，兩組都至少要有一張物品正例。請讓不同拍攝時段、背景或場景分組；連續拍下幾乎相同的畫面不要跨組。完全相同的圖片會自動去重，但近似圖片仍需你自行分組。
6. 按「匯出資料集」可取得 `data.yaml` 路徑。每次建立獨立快照，不覆蓋先前資料。標註工作區預設在 `data/object_detection/`，包含原圖副本、`annotations.json`；匯出在其 `exports/` 內，含 `images/train`、`images/val`、`labels/train`、`labels/val`。
7. 選擇本地起始權重，設定 epochs、batch，按「開始微調」。預設 epochs 150、batch 4、imgsz 640、workers 0，CUDA 可用時使用 GPU；凍結前10層保留預訓練特徵。這只是小資料設定起點；若記憶體不足可降低 batch。訓練在子程序執行，主視窗可繼續操作。每次輸出到獨立 `tranning/object_detection_runs/<識別碼>/`，紀錄放在 `output/object_detection_logs/`。
8. 成功後自動選擇該次的 `weights/best.pt`，再按「使用自訂模型即時偵測」。也可手動選擇舊的 best.pt，模型類別必須與目前資料集相同。未選權重或權重不存在時會提示，不會退回通用模型冒充自訂辨識。

小資料微調會明確設定 `nbs=batch`，避免沿用名義 batch 64，讓 batch 4 的少量資料要累積約 16 批才更新一次參數。另使用 `AdamW`、`lr0=0.001`、`warmup_epochs=0`、`cos_lr=True`、`freeze=10`，增強為 `degrees=15`、`mosaic=0.2`、`close_mosaic=10`、`scale=0.3`。epochs 預設為150，可自行調整。這些設定已在本次50張快照進行真實比較，仍不代表泛化品質有保證；訓練會列出每類框數及缺少訓練／驗證類別警告，請用獨立場景檢查結果。

中文名稱使用 Tk 畫布顯示，不需要下載字型。鏡頭索引預設 0；若有多台攝影機可改成 1 等數字。停止鏡頭後要等待背景執行緒釋放，才能再次開啟。關閉視窗前若有訓練進行中，先按「停止訓練」並等候結束；強制停止不保證產生完整模型。

訓練入口關閉圖表輸出，並在該次 `model.train()` 呼叫範圍暫停 Ultralytics 8.4.90 的資料檢查字型下載；資料與標註驗證仍照常執行，結束或出錯時會還原。此處不需使用訓練圖表字型，中文即時畫面由 Tk 負責。

命令列微調也可使用同一份匯出資料：

```powershell
.\.venv\Scripts\python.exe tranning/object_detection_train.py --data data/object_detection/exports/<識別碼>/data.yaml --weights yolo11n.pt --epochs 150 --batch 4
```

所有資料/模型輸出必須在專案內。照片匯入只讀取來源、另存副本；原圖不會被修改。標註是你的人工答案，模型訓練後仍可能誤判；請以未參與訓練的不同場景照片檢查漏判、誤判與各類別指標。請蒐集不同角度、距離、光線、遮擋與相似物品；沒有固定張數能保證準確率。此功能不處理人物身分辨識。
